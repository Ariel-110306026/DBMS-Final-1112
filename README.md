Project Overview

This project was developed as a database and information system project, focusing on the design and implementation of a system supported by a relational database.

The repository contains the database system, front-end components, testing materials, and supporting project materials developed during the project.

Project Context

The project was designed around a practical information-system scenario rather than database operations alone.

The system therefore considers how information is collected, stored, retrieved, and used to support operational activities.

System Objective

The primary objective was to transform a real-world operational scenario into an implementable information system by connecting:

- business requirements;
- data entities and relationships;
- database design;
- application logic;
- user-facing interfaces.

Information System Perspective

The system can be understood through the following flow:

Business Requirements
        ↓
Business Entities / Processes
        ↓
Database Design
        ↓
Application Logic
        ↓
User Interface
        ↓
Operational Information

This project demonstrates the relationship between organizational processes and information technology.

Database Design

The database component focuses on representing operational information through structured relational data.

Important design considerations include:

- identifying relevant entities;
- defining relationships between entities;
- reducing unnecessary data duplication;
- maintaining data consistency;
- supporting operational queries;
- connecting database information with application functions.

System Components

The repository is organized into several components, including database-related source code, front-end components, testing materials, and project documentation.

The major components include:

- "DBMS/" — database-oriented application implementation;
- "DBMS_final_front/" — front-end component;
- "DB_part-time training system/" — business scenario-oriented system component;
- "TestWeb/" — web/system testing component;
- "Report material/" — supporting project materials.

Technology

- Java
- MySQL
- MySQL Connector/J
- Eclipse-based Java project structure
- Web/front-end components

My Contribution

This project was completed as part of a collaborative project environment.

My experience from this project includes working with database-oriented system implementation and understanding how different system components need to work together.

When presenting this project, I distinguish between the parts I personally implemented and the parts developed collaboratively.

Key Learning

The most important lesson from this project was that database design should be driven by information requirements rather than treated as an isolated technical task.

A database becomes useful when its structure supports the processes and decisions of the people using the system.

Challenges

One of the main challenges was connecting different layers of the system.

A change in the database structure can affect application logic and the user interface. This experience highlighted the importance of considering the system as an integrated whole rather than developing each component independently.

Information Management Reflection

From an Information Management perspective, this project helped me understand the relationship between:

Business Process → Information Requirements → Database → Application → User

This perspective later became important to my interest in business process visualization and the practical application of information systems.
